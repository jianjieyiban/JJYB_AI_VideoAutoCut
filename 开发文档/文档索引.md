## 真实技术栈

- 桌面与 Web：Flask、Flask-SocketIO、PyWebView、HTML/JavaScript/Layui。
- 数据：SQLite 与 `backend/database/db_manager.py`。
- 视频：FFmpeg/ffprobe、OpenCV、MoviePy、ImageMagick 资源。
- 音频：librosa、SoundFile、Pydub、Edge TTS、gTTS、pyttsx3、可选 Azure/Coqui。
- 视觉与 AI：可配置的云端模型适配器、PyTorch、YOLO、faster-whisper、可选 Whisper/FunASR。
- 图像生成：DALL-E 3、通义万相、文心一格、腾讯混元、智谱 CogView、豆包生图、SiliconFlow、自定义 OpenAI 兼容网关。
- 本地声音复刻：独立 Python 3.10 worker 调用 `models/index-tts/`。

## 开发原则

1. 以真实处理结果为准；智能分析、模型请求或渲染失败时返回明确错误，不用伪造结果代替。
2. 调用声音复刻必须取得参考音频权利人授权。
3. 外部模型通过用户配置的 API Key、Base URL 和模型名接入；不承诺某个服务商或模型一定可用。
4. 主程序与 IndexTTS2 worker 使用不同 Python 环境，不能把二者依赖当作同一环境维护。
5. 剪映草稿导出支持原生格式（检测到剪映草稿目录时）和通用草稿包两种模式。

## 模型配置隔离

项目支持三类独立的模型配置，互不干扰：

| 类型 | 配置类 | 用途 | 独立字段 |
|---|---|---|---|
| 文本模型 (LLM) | LLMConfig | 文案生成、脚本优化、文案质检 | custom_openai_api_key/base_url/model |
| 视觉模型 (VLM) | VisionConfig | 视频画面分析、场景识别 | custom_openai_api_key/base_url/vision_model |
| 图像生成 | ImageGenConfig | AI 封面生成 | custom_openai_api_key/base_url/model |

三类模型的 API Key、Base URL 和模型名完全独立存储和读取，不会互相覆盖或回退。
设置页面有三个独立的配置卡片，分别对应三类模型。

- 检查 `.gitignore` 是否排除本地配置、SQLite、上传、输出、日志、缓存及模型权重。
- 检查所有第三方字体、音乐、模型、源码和二进制资源的许可证。
- GitHub 仓库地址：https://github.com/jianjieyiban/JJYB-AI-ZhiJian （私有仓库）

## 三处解说风格联动（v3.1.0+）

原创解说界面有三处风格功能选项，已实现联动：

| 位置 | 名称 | 控制维度 |
|---|---|---|
| 第1处 | 风格预设仪表板 | 12种视频类型一键套用（自动同步下方所有参数） |
| 第2处 | 文稿风格配置 | 12种文稿风格 + 4种情感基调 + 12种解说类型 + 10种钩子 |
| 第3处 | 写作人格面板 | 12种写作人格 + 4种叙事视角 + 5档语速 + 4档情感浓度 |

联动逻辑：选第1处风格卡片 → 自动同步第2处 scriptStyle/hookType + 第3处 cxNarrationStyle。
