# 可发布源文件清单

本清单用于 `jianjieyiban/JJYB-AI-ZhiJian` 的公开发布盘点，路径均相对于项目根目录。清单仅包含可公开分发的源码、文本配置、文档及必要的文本资源；每个推送文件均以完整内容提交，不使用分段内容。

## 本项目源码与文档

- `backend/`：`api/`、`config/`、`core/`、`database/`、`engine/`、`prompts/`、`services/`、`utils/`、`workers/` 下的 Python 源码及包初始化文件。
- `backend/assets/README.md`：内置资源说明；音频、字体等二进制素材不在本清单上传范围。
- `frontend/app.py`：Flask / SocketIO 应用入口。
- `frontend/templates/`：所有 HTML 页面模板。
- `frontend/static/js/`、`frontend/static/favicon.svg`：自有前端脚本和图标。
- `frontend/static/lib/`：仅文本格式的前端库文件；二进制字体文件不上传。
- `config/config.yaml`、`config/censor_words.json`：不含密钥的应用配置。
- `scripts/check_system.py`、`scripts/start_flask.py`、`requirements.txt`、`启动应用.bat`、`.gitignore`、`README.md`。
- `开发文档/`：维护者文档和索引。

## IndexTTS 源码（不含权重）

- `models/index-tts/` 下的 Python、C/CUDA/C++/头文件、JSON/YAML/TOML、文本、许可证、工作流和文档均属于可发布源码候选。
- `models/index-tts/checkpoints/` 及其缓存、模型文件和权重不上传；其中与权重一同分发的配置文本不作为独立发布内容处理。

## 明确排除

- 版本控制、IDE 与环境目录：`.git/`、`.venv/`、`venv/`、`env/`、`__pycache__/`、IDE 文件夹。
- 本地自动化缓存：`.playwright-cli/`、测试截图、浏览器页面快照和临时调试文件。
- 敏感或本地状态：`.env`、`config/ai_config.json`、`database/*.db`、`*.pyc`。
- 运行数据：`logs/`、`uploads/`、`temp/`、`output/`、`outputs/`、`storage/` 的内容（只保留必要 `.gitkeep` 占位；媒体、缓存、试听、压缩包和剪映草稿包不提交）。
- 模型权重与下载缓存：`*.pt`、`*.pth`、`*.safetensors`、`*.bin`、`*.t7`、TensorFlow SavedModel 文件等。
- 二进制/再分发待核验资源：音视频、图片、字体、`resource/imageMagick/` 内文件及 ImageMagick 可执行文件。
- 所有 `*.zip` 文件。

## 传输原则

若文本源码或文档超过当前 GitHub MCP 的可靠单文件传输容量，不拆分、不截断，状态记为“在 Release ZIP 已完整包含，MCP 无法可靠传输”。
