## 一、快速上手

### 1.1 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64位） |
| Python | 3.10 ~ 3.13 |
| FFmpeg | 已安装并加入 PATH（`ffmpeg` 与 `ffprobe` 均可用） |
| 网络 | 使用云端 AI 功能时需联网；纯本地功能可离线 |

### 1.2 启动软件

1. 解压下载的源码包，进入项目目录。
2. 首次使用先安装依赖：`py -3 -m pip install -r requirements.txt`。
3. 双击 **`启动应用.bat`**，浏览器会自动打开软件界面（默认本地服务）。

### 1.3 界面总览

启动后进入全局框架界面：

- **左侧导航栏**：当前项目、最近项目、快速工具（AI配音 / 自动字幕 / 智能混剪 / 画面增强）。
- **顶部栏**：应用 Logo、通知中心（铃铛）、用户菜单（个人中心 / 设置 / 退出）。
- **右侧面板**：当前工作区状态、剪辑属性、色彩校正、特效、导出设置。

所有功能页面（混剪、解说、配音等）都从侧边栏或首页的入口卡片进入。

### 1.4 一键升级（v3.3.3 起支持）

1. 进入 **设置 → 快捷操作 → 检查更新**。
2. 若发现新版本，会弹出升级窗口，展示新版本号、更新日志和更新包大小。
3. 点击 **一键升级**，软件自动完成：下载 → 校验 → 覆盖更新 → 自动重启。
4. 你的项目数据、API Key、配置、素材全部保留，无需重新配置。

> 提示：更新通道（稳定版 / 测试版 / 关闭）在 **设置 → 高级设置 → 自动更新** 中选择。

## 二、混剪模式（核心功能一）

**用途**：把一条或多条原始素材，自动剪成节奏流畅、无片头片尾、无重复镜头的成片。支持"大众混剪"和"音乐卡点"两种模式。

### 2.1 进入混剪

侧边栏或首页点击 **智能混剪**，进入「混剪模式 · AI智能版」页面。

### 2.2 第一步：选择混剪模式

页面顶部有两张模式卡片，按需选择：

| 模式 | 适合场景 | 特点 |
|---|---|---|
| **大众混剪** | 影视混剪、素材合集、解说底片 | 按"高光识别"选片段，保持原时间线叙事顺序 |
| **音乐卡点** | 卡点视频、快节奏合集 | 先分析音乐节拍（librosa 节拍检测），镜头切换对齐鼓点 |

### 2.3 第二步：项目配置

| 配置项 | 说明 | 建议 |
|---|---|---|
| 项目名称 | 用于在项目中心识别 | 写清楚主题，如"三体混剪- Part2" |
| 目标时长 | 成片总时长，可用快捷时长或自定义 | 短视频建议 30~60 秒 |
| 混剪手法模板 | 不同风格影响片段平均时长与节奏 | 快节奏选短片段模板 |
| 输出质量 | 编码质量档位 | 发布平台选"高清"，先看效果选"快速" |
| 视觉模型 | 可选，启用多模态大模型理解画面内容 | 要求"看懂内容"的混剪开启 |

### 2.4 第三步：上传素材并生成

1. 点击上传区域选择一个或多个视频文件（也支持从素材库选择）。
2. 点击 **开始生成**，进度条会依次显示三个阶段：
   - **检测**：智能镜头分割（TransNetV2 深度学习检测，失败自动回退 OpenCV），并做**片头片尾剔除**（黑场检测 + 低信息画面 + 首尾比例保护 + 多素材片头模板识别）；
   - **评分选片**：多信号融合评分（画面运动 + 色彩 + 亮度 + **音频能量** + **人物出镜**），自动**感知哈希去重**——相似画面只保留得分最高的一个，并从候选池自动补位；
   - **合成**：按时间线切割、拼接、加转场 / BGM / 配音（按你勾选的自动化选项）。
3. 完成后可直接预览、下载成片，或进入编辑器微调。

### 2.5 自动化选项详解（按需勾选）

| 选项 | 作用 |
|---|---|
| 自动识别精彩片段 | 开启多信号高光评分（v3.4.0 起含音频能量与人物出镜信号） |
| 自动添加转场效果 | 相邻片段间加转场；选"硬切"则不加 |
| 自动添加背景音乐 | 从 BGM 库或本地上传选择，普通模式为替换音轨 |
| 自动生成配音 | 调用 TTS 为混剪配旁白 |

### 2.6 音乐卡点模式专有设置

- **BGM 文件**：上传或选择音乐文件，程序先做节拍分析。
- **卡点灵敏度**：越高切得越密。
- **节奏匹配**：镜头时长贴合节拍间隔；镜头不足时自动复用高分镜头。
- **速度曲线**：可选慢/快慢结合等曲线，配合卡点更有冲击力。

### 2.7 高级选项（可选）

- **剪辑规则与时间轴优化**：片段最短/最长时间、转场密度。
- **技术性能优化**：分析帧采样间隔（越小越准越慢）、并发数。
- **跨平台适配**：目标平台（抖音 / B站 / 快手等）、分辨率、码率控制。
- **防查重变换**：随机镜像、轻微放大、调色微调（`ai_dedup_engine`），降低平台判定搬运的概率。

> **调参技巧**：第一次跑完不满意时，**不要换素材**，先调参数重跑——镜头检测结果已缓存（同文件秒级返回），只有选片和合成会重新执行，速度比第一次快很多。

## 三、原创解说剪辑（核心功能二）

**用途**：给一条素材自动生成解说文案、配音、字幕，并让画面与解说**逐段对齐**，产出完整解说视频。

### 3.1 第一步：项目设置（解说风格）

1. 在风格仪表板中选择解说风格预设（如幽默吐槽、专业测评、温情叙事等）。
2. 每张风格卡片下有参数预览：语速倾向、句式风格、钩子类型。
3. 点 **立即应用此风格** 确认。风格会传入文案生成（LLM）环节。
4. 项目参数：项目名、目标时长、是否启用花字特效（花字范围 / 频率 / 同步音效）。

### 3.2 第二步：上传视频素材

- 拖拽或点击上传本地视频（支持常见格式），或点 **从已上传素材选择** 复用素材库里已有的文件。
- 上传后点 **开始分析**，程序做"视频内容深度理解"：镜头分割 + 逐镜头视觉特征提取（可选接视觉大模型理解画面语义）。

### 3.3 第三步：生成解说文案

1. 分析完成后点 **生成解说文案**。
2. 文案按解说段落划分，每段对应一段画面窗口；分镜规划器会把长镜头切成不重叠窗口，按语义相关、锚定位置、连续性、覆盖度、画面质量综合打分后分配给每段解说。
3. 你可以**手动编辑每一段文案**再进入下一步——推荐通读一遍，AI 文案难免有错别字或菜名/人名识别误差。

### 3.4 第四步：AI语音合成（TTS）

1. 选择 TTS 引擎与音色（详见[第四章](#四ai智能配音核心功能三)）。
2. 点 **生成配音**，逐段合成并实测每段音频时长。
3. 可选：自动生成字幕、自动添加背景音乐、音量控制（解说 / 原声 / BGM 三轨分别调节）。

### 3.5 第五步：音画同步合成

点 **开始同步**，进入"拟人化同步"引擎：

- 每段画面窗口的时长**以对应配音的实测时长为准**逐段对齐；
- 画面比音频长：截取中段最精华部分；画面比音频短：轻微慢放（最低 0.25x，低于则拒绝并提示）；
- 每个视频片段渲染后逐段实测时长校准音频，**杜绝越到片尾音画越偏**的问题；
- 全部段落后拼接视频轨与音频轨（解说 + 原声 + BGM 混音），输出成片。

### 3.6 导出与剪映联动

- 直接导出 MP4；
- 或导出 **剪映草稿**（在剪映里继续精修，轨道结构与本软件一致）。

## 四、AI智能配音（核心功能三）

**用途**：独立把一段文字变成语音，支持云端大厂音色与本地声音克隆。

### 4.1 第一步：选择 TTS 引擎

| 引擎 | 说明 | 需要配置 |
|---|---|---|
| Microsoft Azure TTS | 音色自然、语种多 | Azure 密钥（设置页配置） |
| 火山引擎 | 中文表现好，支持声音克隆 | 火山引擎密钥 |
| Google TTS | 简单稳定 | Google 密钥 |
| IndexTTS2 本地克隆 | 完全本地运行，不上传任何音频 | 无需 API，需本地算力 |

### 4.2 第二步：输入文本并选择音色

- 中文音色 / 英文音色分区选择，每个音色可点 **试听**；
- 调节 **语速 / 音调 / 音量** 三个滑杆；
- 高级用户可展开"TTS声学模型配置"（声码器、韵律预测、情感 TTS、说话人嵌入等，默认参数即可满足大多数场景）。

### 4.3 第三步：声音克隆（以火山引擎 / 本地克隆为例）

1. 上传参考音频（**必须是你有权利使用的声音**，软件会要求勾选授权确认）。
2. 输入要合成的文本。
3. 点 **生成**，完成后可试听并下载到指定文件夹。

> 版权提醒：克隆他人声音前必须获得本人明确授权，使用克隆功能即表示你已确认拥有参考音频的合法权利。

### 4.4 批量配音

解说页的"生成配音"即批量模式：按解说段落逐段合成、逐段实测时长，直接服务音画同步，无需手动对齐。

## 五、视频编辑器

首页（工作台）即编辑器主体，用于手动微调 AI 产出或从零开始创作。

### 5.1 界面分区

| 分区 | 功能 |
|---|---|
| **当前项目** | 显示项目名、创建/修改时间；未选项目时提示"开始创作您的视频" |
| **素材库**（左栏） | 视频素材 / 音频素材 / 图片素材 快速取用 |
| **AI工具** | 一键进入混剪、解说、配音、自动字幕等 AI 功能 |
| **编辑工具** | 撤销、重做、保存、导出等常用操作 |
| **视频预览**（中央） | 实时预览画面，支持画质切换与全屏预览 |
| **时间轴**（下方） | 片段排列、拖拽调整顺序与长度、剪辑点微调 |
| **右侧属性面板** | 剪辑属性（位置 / 缩放 / 旋转 / 音量）、色彩校正（亮度 / 对比度 / 饱和度 / 色调）、特效（滤镜 / 转场 / 视觉效果）、导出设置（格式 / 分辨率 / 帧率） |

### 5.2 基本操作流

1. 新建或打开项目（项目中心 / 最近项目）。
2. 从素材库拖素材到时间轴。
3. 在预览窗口定位，用分割工具剪开，删除多余段。
4. 右侧面板调属性 / 调色 / 加特效。
5. `Ctrl+S` 保存，导出设置里选择参数后点 **导出**。

### 5.3 快捷操作

- **保存**：`Ctrl+S`
- **撤销 / 重做**：编辑工具栏按钮
- **全屏预览**：预览窗口右上角按钮
- 界面支持 **中英双语切换**（设置 → 语言与区域）

## 六、后台管理界面

### 6.1 项目中心（projects.html）

- **项目列表**：所有项目卡片，支持搜索、打开、重命名、删除；勾选多项目可**批量删除**（有二次确认弹窗）。
- **项目模板**：把常用配置（风格、时长、质量）存为模板，新建项目一键套用。
- **最近活动**：时间线形式展示近期生成、导出、修改记录。
- **项目设置**：项目级参数（覆盖全局默认）。

### 6.2 素材库（materials.html）

- **四个标签页**：视频素材 / 音频素材 / 图片素材 / 文字模板。
- **上传**：拖拽文件到虚线框即可上传，也可点击选择。
- **素材列表**：缩略图 + 时长 + 大小；支持**收藏**（进收藏夹）、预览、下载、删除（二次确认）。
- **最近使用**：快速找到刚用过的素材。
- **存储统计**：查看素材占用空间，方便清理。

### 6.3 系统设置（settings.html）

左侧菜单共 8 个标签页：

**① API配置中心**（最常用）
- **AI大模型API**：预置 OpenAI / Anthropic / Google / 月之暗面 / 讯飞 / 阿里云 / 百度 / 智谱 / DeepSeek / OpenRouter / SiliconFlow / 字节跳动，也支持"自定义 OpenAI 兼容服务"（填 Base URL + Key 即可接入任意兼容中转）。
- **视觉模型API**：画面理解用（解说分析、混剪视觉识别）。
- **语音模型API**：Azure TTS、火山引擎语音克隆、常规TTS运行设置。
- **封面生成模型API**：DALL-E 3 / 通义万相 / 文心一格 / CogView / 豆包生图 / SiliconFlow 聚合图像 / 自定义 OpenAI 兼容。
- **全局默认参数**：模型温度、最大 tokens 等兜底值。
- 填好 Key 后点 **保存设置**，顶部"配置说明"有详细指引；"快速操作"里有原创解说 / 混剪 / AI配音 / 编辑器四个直达按钮。

**② 外观个性化**：深色 / 浅色 / 跟随系统主题，动画效果、玻璃态效果开关、默认折叠右侧属性栏。

**③ 语言与区域**：简体中文 / English，切换即时生效并记忆。

**④ 文件设置**：输出目录、素材目录、缓存目录管理。

**⑤ 通知设置**：任务完成 / 失败提醒方式。

**⑥ 性能设置**：并发数、硬件加速（依硬件能力检测自动推荐）。

**⑦ 高级设置**：代理设置、自动更新通道（稳定版 / 测试版 / 关闭）。

**⑧ 关于**：版本信息、开源协议（含 GitHub 仓库直达链接与"发布页下载"）、**检查更新 / 一键升级**（快捷操作区）、帮助中心、详细信息。

### 6.4 通知中心

顶部铃铛图标：实时同步任务状态（基于项目数据），支持全部已读、清空、刷新。后台合成任务完成或失败都会在这里提醒。

## 七、常见问题 FAQ

**Q1：生成的片子还有片头片尾？**
v3.4.0 起已内置四层片头片尾剔除（黑场 + 低信息画面 + 首尾比例保护 + 多素材片头模板）。若素材的片头是复杂动态画面，可在"高级选项"调大首尾保护秒数。

**Q2：混剪出现重复镜头？**
多信号评分后已自动做感知哈希去重并补位。如仍出现，多为素材本身高度雷同（如同机位连拍），建议换用不同角度的素材。

**Q3：音画不同步？**
解说模式已逐段实测校准。若用外部剪辑后出问题，检查导出帧率是否与项目设置一致。

**Q4：第一次分析很慢，重跑还要等吗？**
不用。镜头检测结果按"文件 + 修改时间"缓存，同一素材调参重跑秒级完成；只有换素材或改文件才会重新检测。

**Q5：无声视频能混剪吗？**
能。程序自动检测无音轨并关闭音频信号，把权重重新分配给画面特征。

**Q6：一键升级失败？**
检查网络 / 代理（设置 → 高级设置）；也可到 GitHub 发布页手动下载覆盖升级，数据不会丢失。

**Q7：API Key 安全吗？**
所有 Key 仅保存在你本地配置文件中，不随项目导出、不进入 Git 仓库（已在 .gitignore 排除）。

**Q8：支持英文界面吗？**
支持。设置 → 语言与区域 → English，全界面即时切换。
